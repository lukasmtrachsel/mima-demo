# Mima – Demo

Interaktive Demo von **Mima**: ein Zoo, der mit gesunder Bildschirmzeit wächst.

**Ausprobieren:** https://lukasmtrachsel.github.io/mima-demo/

- An jedem Tag, an dem das Tagesziel eingehalten wird, wächst das Tier: Ei, Baby, Kind, Jugendlich, Erwachsen.
- Zu viel Bildschirm macht das Tier müde, aber nie krank. Im Sperrmodus schläft es auf dem Sperrbildschirm.
- Erwachsene Tiere ziehen in den Zoo, neue Bereiche öffnen sich, jede Art hat einen Steckbrief.
- Im Lernteil «Nachrichten-Detektiv» lernen Kinder mit der Eule Olli, gefälschte Nachrichten zu erkennen.

In der Demo wird die Zeit mit Knöpfen vorgespult. Alle Daten bleiben im Browser.
Die echte App läuft unter Windows und misst die Bildschirmzeit selbst.
